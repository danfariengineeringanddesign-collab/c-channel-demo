.CATScript and .swb are generated here in the browser, no server, no CATIA/SolidWorks needed to download them. Run the .CATScript in CATIA (Tools > Macro > Macros) or run the .swb in SolidWorks (Tools > Macro > Run) — both create exactly the section and length you selected, no typing. The .STEP button downloads a pre-generated STEP file from the step/ pack (12, 24, 36, 48, 60, 72, 96, 120, 144 in). For any other length, use .CATScript or .swb, which are generated in the browser for exactly the length you selected.
STEP works with any CAD that imports STEP — Inventor, Fusion 360, Solid Edge, Onshape, Creo, NX, FreeCAD, Rhino. STEP is a solid, not parametric; parametric macros are for CATIA and SolidWorks only.
